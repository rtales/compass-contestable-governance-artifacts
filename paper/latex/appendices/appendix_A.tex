\section{Reproducibility and Revision Evidence}
\label{app:repro}
The revision preserves the historical sources and numerical assets in a checksum-indexed snapshot. A version inventory and work log are maintained in the accompanying \texttt{revisao\_artigo} directory. The reference repository is \CompassRepoURL; local revised code and hashes, rather than the unmodified remote HEAD, identify the changes evaluated here.

The historical packet runs used are ASSISTments, OULAD and synthetic snapshots from 26 January 2026, all seed 42. Their full paths and SHA-256 digests appear in the computational revision report. No new fit of those historical models is claimed.

\paragraph{Rebuilding the analysis.}
From the project root, the script \path{revisao_artigo/scripts/recalcular_evidencias.py} regenerates computational reports, candidate tables, group-risk summaries, study aggregates and the English diagnostic figure. It uses the preserved case packets and, for the study, the author's local response ZIP. The author confirmed the original assignment mapping in this revision. Outputs are in \path{paper_assets/revised/}. Individual response text is not copied to those outputs.

The report records complete thresholds, capacities, IDs, counts and comparisons with historical CSVs. Fixed-budget and full-grid results have separate domains. Script source and an environment lock accompany the revision. Application tests include a synthetic end-to-end run and corruption checks; they do not substitute for re-fitting real-data predictors.

\paragraph{Access limitations.}
Historical packet labels and audit groups are retrospective evaluation data. Participant responses remain local in this revision; sharing consent and institutional rules must be checked before redistribution. Aggregate counts and scripts are included. A computational reproduction can run without the study data and must report the study as skipped, never silently substitute generated participants. The revised study analysis was retrospective, not preregistered.

\paragraph{Compilation and verification.}
The multi-file LaTeX project is compiled with Tectonic, with its release recorded in the revision tools inventory. Generated tables use unrounded metrics and round only for display. All rendered pages are inspected for clipping and broken references. Source snapshots, checksums, software versions and verification records distinguish the historical release from this corrected draft.
